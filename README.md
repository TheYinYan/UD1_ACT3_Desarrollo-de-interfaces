Realiza las siguientes tareas para trabajar con fuentes:

0.- Investiga por internet cuales son las fuentes más apropiadas para utilizar en la web, y los motivos.

1.- Identifica cuales son las principales safe fonts. Crea una página web sencilla, como en el ejemplo, donde se muestre tu nombre, el ciclo y la asignatura. Utiliza diferentes safe fonts para cada una de las 3, y asegúrate de que no hay problemas en su visualización, independiente del sistema operativo/navegador que utilicemos.

2.- Fuentes alojadas en el servidor: obtén una fuente ttf de internet, o elige una disponible en el sistema y transfórmala al formato .woff.  Añádelo a tu servidor (carpeta fonts) y muestra una página web que haga uso de dicha fuente. Demuestra que se ve bien en diferentes navegadores. ( Debes de investigar programas para convertir fuentes ttf a woff ).

3.- En la misma página, utiliza diferentes google fonts, con etiquetas <link> o etiquetas @import.
